# ATLAS

Ты открываешь новый терминал и понятия не имеешь, откуда берётся `PATH`, почему
git подписывает коммит не тем email, и в каком из пяти `.npmrc` прописан прокси.

ATLAS отвечает на эти вопросы. Он сканирует macOS, строит карту всех конфигов
и показывает её в терминальном интерфейсе с поиском и превью. Ничего не меняет —
только читает.


## Установка

Нужен [`uv`](https://docs.astral.sh/uv/getting-started/installation/). Если его нет:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Клонируй репозиторий и создай команду `atlas`:

```sh
git clone https://github.com/GringoCoco/atlas ~/Projects/atlas
```

Добавь в `~/.zshrc` (или `~/.bashrc`):

```sh
alias atlas='uv run --quiet --script ~/Projects/atlas/atlas_tui.py'
```

Перезапусти терминал или выполни `source ~/.zshrc`. Теперь достаточно:

```sh
atlas
```

## Использование

```sh
atlas                   # интерактивный TUI
atlas --list            # текстовый список — удобно для grep/less
atlas --chains          # цепочки приоритета: какой файл реально применяется
atlas --env             # переменные окружения и где они заданы
atlas --grep proxy      # поиск по содержимому файлов
atlas --json            # JSON-выгрузка карты
```

### Навигация

| Клавиши | Действие |
|---|---|
| `↑` `↓` / `PgUp` `PgDn` | перемещение |
| `Enter` | открыть превью файла |
| `Tab` / `Shift-Tab` | переключить режим |
| `Esc` | сбросить запрос / фильтры |
| `Ctrl+Y` | скопировать путь в буфер обмена |
| `Ctrl+O` | открыть в `$EDITOR` |
| `Ctrl+F` | показать в Finder |
| `Ctrl+R` | пересканировать |
| `/` | палитра команд и категорий |
| `F1` | справка |
| `Ctrl+C` | выход |

В превью: `c` — путь, `o` — редактор, `f` — Finder, `m` — показать/скрыть секреты, `Esc` — закрыть.

### Режимы (Tab)

| Режим | Что показывает |
|---|---|
| **Все конфиги** | полный список с поиском |
| **Приоритет** | какой файл применяется, какой перекрыт |
| **Окружение** | где задана каждая переменная — файл и строка |
| **Пакеты** | установленные пакеты по менеджерам (brew, npm, pip…) |
| **Grep** | поиск по содержимому файлов |

### Диагностика (`/`)

Введи `/` и выбери команду из палитры:

| Команда | Что делает |
|---|---|
| `/trace PATH` | откуда берётся переменная — все файлы, строки, значения |
| `/diff` | что видит IDE vs новый терминал: расхождения в окружении |
| `/gitaudit` | на какой email пойдёт следующий коммит в каждом репо |
| `/sshcheck` | какие ключи есть, загружены ли в агент, нет ли проблем |
| `/stale` | захардкоженные пути к версиям вроде `python@3.11/3.11.2/` |
| `/orphan` | конфиги приложений, которых больше нет в системе |
| `/scan` | файлы с токенами и паролями, которые отслеживает git |
| `/export` | сгенерировать `setup.sh` для переезда на новый Mac |

### Категории

`/ai` `/git` `/github` `/ssh` `/net` `/shell` `/node` `/py` `/docker` `/ide` `/macos` `/apps`

### Переменные окружения

Режим «Окружение» показывает каждую переменную и **где** она задана:

```
PATH   задана 9 раз — действует последняя
  ~/.profile:2     "$PATH:~/.docker/bin"
  ~/.zshrc:115     ~/.opencode/bin:$PATH
NVM_BIN
  ⚙ только в окружении   ~/.nvm/versions/node/v22.0.0/bin
```

`⚙ только в окружении` — переменная есть, но ни в одном конфиг-файле не задана.
Скорее всего, её выставил IDE, launchd или родительский процесс.

## MCP-сервер

ATLAS включает MCP-сервер — его можно подключить к любому AI-ассистенту,
который поддерживает [Model Context Protocol](https://modelcontextprotocol.io/).
После подключения ассистент сам будет знать карту твоих конфигов и сможет
отвечать на вопросы вроде «где задан прокси?» или «почему не подхватывается
`.nvmrc`?».

### Инструменты

| Инструмент | Что делает |
|---|---|
| `find_configs` | найти конфиги по названию, пути или описанию |
| `read_config` | прочитать файл (секреты скрыты по умолчанию) |
| `explain_config` | какой файл из цепочки применяется и почему |
| `grep_configs` | поиск по содержимому файлов с номерами строк |
| `list_env` | переменные окружения и где они заданы |
| `list_chains` | цепочки приоритета конфигов |
| `map_overview` | сводка: сколько путей, цепочек, переменных |
| `trace_env_var` | полная трассировка переменной окружения |
| `diff_env` | расхождения между IDE и терминальным окружением |
| `git_audit` | email и имя для каждого git-репозитория |
| `ssh_audit` | аудит SSH-ключей и конфига |
| `find_stale_refs` | захардкоженные пути к версиям пакетов |
| `find_orphans` | конфиги удалённых приложений |
| `scan_secret_leaks` | секреты в git-tracked файлах |
| `generate_export` | скрипт воспроизведения среды |

### Подключение

MCP-сервер запускается как отдельный процесс и общается через stdin/stdout
(стандартный транспорт для локальных MCP-серверов).

**Claude (через CLI):**

```sh
claude mcp add atlas -- uv run --quiet --script ~/Projects/atlas/atlas_mcp.py
```

**opencode** — добавь в `~/.config/opencode/opencode.jsonc`:

```jsonc
"mcp": {
  "servers": {
    "atlas": {
      "type": "local",
      "command": ["uv", "run", "--quiet", "--script",
                  "~/Projects/atlas/atlas_mcp.py"],
      "enabled": true
    }
  }
}
```

**Другие клиенты** (Cursor, Zed, любой MCP-совместимый) — укажи команду:

```
uv run --quiet --script ~/Projects/atlas/atlas_mcp.py
```

### Почему окружение читается из login-shell

Когда ассистент вызывает MCP-сервер, процесс запускается без полного
окружения терминала — часть переменных отсутствует. ATLAS специально читает
`zsh -l -i -c env`, чтобы получить ровно то же окружение, что будет в новом
терминале. Результат кэшируется на 2 минуты.

## Обозначения

| Символ | Значение |
|---|---|
| `●` | файл существует |
| `○` | файл не существует |
| `▸` | папка |
| `→` | симлинк |
| `✓` | файл применяется (выигрывает в цепочке) |
| `✗` | файл перекрыт другим |
| `↩` | тот же файл, уже показан выше |

## Безопасность

Секреты в превью скрыты по умолчанию. Маскируются значения по ключам
`token`, `secret`, `password`, `api_key`, и аналогичным; длинные
base64/hex-строки; пары `user:password` в URL. Команда `/secrets`
или клавиша `m` в превью показывает реальные значения.

MCP-сервер тоже маскирует секреты — реальные значения не попадают в ответы
ассистенту без явного `reveal_secrets=true`.

## Структура

```
atlas_tui.py       TUI-интерфейс (Textual)
atlas_mcp.py       MCP-сервер
config_atlas.py    данные, поиск, диагностика (только stdlib — нет зависимостей)
examples/          примеры использования как библиотеки
tools/             тесты и утилиты разработки
```

Слой данных `config_atlas.py` работает без сторонних зависимостей — его можно
импортировать напрямую:

```python
import config_atlas as ca

entries = ca.build_map()
hits = ca.search(entries, "proxy")
```
